# Velora Footwear — E-commerce V2

Included:
- Responsive storefront
- Bengali / English switch
- Product filtering
- Cart saved in browser localStorage
- Checkout form: name, phone, address, district
- Payment method selector: Cash on Delivery / bKash / Nagad
- Automatic WhatsApp order message to Velora: 01674102916
- Order ID generation
- Last order saved locally

Important:
This version is a functional frontend/demo. Real online bKash/Nagad payment requires merchant credentials and a backend/payment gateway integration. Real inventory, customer accounts, admin panel, delivery charge rules and database also require a server/backend.


## Manual bKash / Nagad
Payment number configured for both bKash and Nagad: **01674102916**.
For bKash/Nagad checkout, the customer sees the number and enters a Transaction ID before placing the order. The order details are then sent to WhatsApp.

This is manual payment collection, not an official bKash/Nagad API gateway.
